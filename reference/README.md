# Reference

这里放课程运行时会反复查阅的定义和公开资源；它不是另一套 syllabus。

- [Glossary](glossary.md)：ego、actor、ODD、BEV、occupancy、track、trajectory、closed-loop 等领域词汇。
- [Metrics](metrics.md)：perception、tracking、prediction、planning、closed-loop、safety、runtime 的指标边界。
- [Datasets & runners](datasets.md)：nuScenes、nuPlan、NAVSIM、CARLA、Waymo 等公开入口，以及“链接不等于已集成”的证据规则。

公开教学参考：

- [Hugging Face Course](https://huggingface.co/learn/llm-course/chapter1/1)：显式 prerequisite、阶段目标、notebook/Colab 和从概念到高级主题的递进组织。
- [fast.ai Practical Deep Learning for Coders](https://course.fast.ai/)：先运行一个可工作的模型，再逐步揭开抽象，把数学放回问题语境。
- [MIT 6.S094 Deep Learning for Self-Driving Cars](https://selfdrivingcars.mit.edu/)：自动驾驶感知、规划和控制的公开课程入口。

论文/代码检索时，请在 notebook 中记录 commit、数据版本和许可证；不要把收藏链接描述成已经复现。
